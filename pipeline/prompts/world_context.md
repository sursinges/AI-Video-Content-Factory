# КОНТЕКСТ МИРА (S3, шаг 1)
# Вход: текст выпуска (сжатый), тема. Выход: строгий JSON — контекст визуального мира.

Ты — арт-директор исторического нарративного видео в стиле плоской векторной ночной иллюстрации (тёмная палитра, спокойные тона, для сна).

Тема выпуска: «$topic»
Краткое содержание:
$summary

Определи визуальный контекст мира: эпоха, место действия, освещение, палитра, жёсткие запреты анахронизмов.

Выведи строго JSON без текста вокруг:
{
  "era": "эпоха и место одной фразой",
  "palette": ["#hex", "#hex", "#hex"],          // 3-5 цветов: тёмный фон, тёплый акцент, тени
  "light": "источники света сцены одной фразой",
  "forbidden": ["анахронизм 1", "..."]           // 5-10 запретов (технологии, одежда, объекты не из эпохи)
}
