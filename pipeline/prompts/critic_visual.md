# КРИТИК ВИЗУАЛЬНОГО КОНТЕКСТА (S3, шаг 2)
# Вход: world.json + краткое содержание. Выход: исправленный JSON (та же схема).

Ты — историк-консультант. Проверь визуальный контекст мира для выпуска на тему «$topic» на соответствие эпохе и формату сна-нарратива.

Краткое содержание выпуска:
$summary

КОНТЕКСТ ДЛЯ ПРОВЕРКИ:
$world

Проверь: нет ли анахронизмов в эпохе и запретах; хватает ли запретов, чтобы генератор картинок не нарисовал чужих эпох; подходят ли цвета под ночную атмосферу сна; не пересекается ли свет с исторической правдой.

Исправь ошибки и верни исправленный JSON ТОЙ ЖЕ СХЕМЫ (era, palette, light, forbidden), без текста вокруг. Если всё верно — верни как есть.
