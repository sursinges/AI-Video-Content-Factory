"""Emotional tags prompt (S2). Adds calm narration-style tags for TTS."""
# Variables: $chunk_text (chunk text), $stop_tags — excluded aggressive tags.

Задача: разметь текст для озвучки эмоциональными тегами в квадратных скобках.

Формат «спокойного нарратива»: ровная, гипнотическая подача. Разрешены ТОЛЬКО теги:
[спокойно] [мягко] [тише] [пауза] [вдох] [тепло] [приглушённо]

Правила:
— Плотность: один тег на 1–3 предложения, не чаще.
— [пауза] — перед важной мыслью и после смены темы.
— Запрещены агрессивные теги (крик, возбуждение, страх) — этот профиль подачи их не использует.
— Текст НЕ переписывать: менять только вставкой тегов.
— Не добавляй комментариев — на выход только размеченный текст.

ТЕКСТ:
$chunk_text

Выведи строго JSON: {"text": "размеченный текст целиком"}
